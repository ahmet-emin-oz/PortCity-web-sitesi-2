# 🌊 PortCity - Premium Turizm Web Sitesi

**PortCity** projesine hoş geldiniz! Bu, lüks bir Akdeniz destinasyonu olan PortCity'nin güzelliklerini ve hizmetlerini sergilemek için tasarlanmış modern, duyarlı ve etkileşimli bir web sitesidir.

## 🚀 Özellikler

- **Premium Tasarım**: "Okyanus ve Altın" renk paleti ile görsel olarak çarpıcı, profesyonel bir arayüz.
- **Karanlık Mod (Dark Mode) 🌙**: Göz yormayan, tam uyumlu karanlık tema desteği.
- **Etkileşimli Öğeler**:
  - Büyütülebilen (Zoom) ana sayfa görselleri.
  - "Beğeni" sayacı işlevi.
  - Hangi sayfada olduğunuzu gösteren aktif menü takibi.
- **Dinamik İçerik**: Hizmetler sayfasındaki aktiviteler, JavaScript dizileri (Arrays) ve döngüleri kullanılarak dinamik olarak listelenir.
- **Form Doğrulama**: İletişim formu, boş alan bırakılmaması için kontrol mekanizmasına sahiptir.

## 📂 Proje Yapısı

```
PortCity/
├── index.html       # Ana Sayfa (Hero Görseli, Beğeni Butonu)
├── about.html       # Hakkımızda (Ekip Görseli ve Bilgi)
├── services.html    # Hizmetler (Dinamik JS Listesi)
├── contact.html     # İletişim (Form Doğrulama)
├── style.css        # Genel Stiller (Temalar, Flexbox Düzeni)
├── script.js        # Mantık (Event Listener'lar, DOM Manipülasyonu)
└── images/          # Görseller (Özel Olarak Oluşturulmuş Premium Görseller)
```

## 🛠️ Kullanılan Teknolojiler

- **HTML5**: Semantik yapı ve sayfa düzeni.
- **CSS3**: Flexbox, CSS Değişkenleri (Variables), Geçiş Efektleri (Transitions).
- **JavaScript (ES6+)**: Olay yönetimi (Event Handling), DOM manipülasyonu.

## 📦 Nasıl Çalıştırılır?

1. **Projeyi İndirin**: Bu klasörü bilgisayarınıza kaydedin.
2. **Başlatın**: `index.html` dosyasını favori web tarayıcınızda (Chrome, Edge, Firefox vb.) açın.
3. **Keşfedin**: Temayı değiştirin, görsellere tıklayın ve PortCity'nin keyfini çıkarın!
